# 接触模型

接触模型（contact model）是 PFC 中定义**颗粒之间、颗粒与墙体之间接触行为**的核心机制。它决定了接触处的力-位移关系，是离散元计算结果是否可信的关键。

> 本章依据 Itasca PFC 官方文档（doc-itasca）与 Potyondy & Cundall 的经典文献整理，公式采用 PFC 约定。

## 接触与力-位移定律

PFC 的计算循环中，每个**激活接触**（active contact）都要执行力-位移定律：根据接触处的**相对位移**更新**接触力**，再把力累加到颗粒上。

- 接触发生在两个"实体"（piece）之间：球-球（ball-ball）或球-墙（ball-facet）。
- 接触平面（contact plane）由接触点处的公切面定义，接触力分解为**法向分量**和**切向分量**。
- 接触是否激活由**表面间隙** $g_s$ 决定：$g_s = g_c - g_r$，其中 $g_c$ 为接触间隙，$g_r$ 为参考间隙。通常 $g_r = 0$，此时 $g_s \le 0$ 表示两实体发生重叠，接触激活。

## 线性模型（Linear）

线性模型是最基本、也是默认的接触模型，命名 `linear`。它由**线性弹簧**（提供弹性、无拉、摩擦行为）与**阻尼器**（提供黏性耗能）并联组成，只传递力、不抵抗相对转动。

接触力由线性分量与阻尼分量叠加：

$$F_c = F^l + F^d$$

**线性力（弹簧）**

- 法向（无拉力）：$F_n^l = k_n\, g_s$（绝对更新模式），其中 $k_n$ 为法向刚度。
- 切向（增量更新）：$(F_s^l)' = F_s^l - k_s\, \Delta\delta_s$，其中 $k_s$ 为切向刚度，$\Delta\delta_s$ 为切向位移增量。
- 库仑滑移限制：若 $|F_s^l| > \mu F_n^l$，则取 $|F_s^l| = \mu F_n^l$（$\mu$ 为摩擦系数）。

**阻尼力（黏性耗能）**

法向阻尼力采用临界阻尼比形式：

$$F_n^d = 2\beta_n \sqrt{m_c\, k_n}\ \dot\delta_n$$

其中 $m_c$ 为接触有效质量，$\beta_n$ 为法向临界阻尼比（0–1），$\dot\delta_n$ 为法向相对速度。切向阻尼同理用 $\beta_s$。

| 关键参数 | 含义 |
|----------|------|
| `emod` / `kratio` | 有效模量与法切刚度比，用于推算 $k_n$、$k_s$ |
| `fric` $\mu$ | 摩擦系数 |
| `dp_nratio` $\beta_n$ | 法向临界阻尼比 |

## 线性接触键模型（Linear Contact Bond）

命名 `linearcbond`。它在线性模型基础上，在接触点处加了一个**点黏结**：一对带法向/切向刚度和强度的弹簧，好比接触点处的一滴胶水。

- 黏结存在时，**抑制滑动**：切向力不受摩擦限制，而受**抗剪强度**限制。
- 黏结允许接触**承受拉力**，拉力受**抗拉强度**限制。
- 黏结破坏规则：
  - 若法向拉力超过抗拉强度 $T_F$（2D 中单位为力），键断裂，法向与切向力**清零**；
  - 若切向力超过抗剪强度 $S_F$，键断裂（若未超过摩擦极限，力不变）。
- 键断裂后，模型退化为**线性模型**（无黏结）。

| 关键参数 | 含义 |
|----------|------|
| `cb_tenf` | 接触键抗拉强度（2D 单位：力） |
| `cb_shearf` | 接触键抗剪强度（2D 单位：力） |

## 线性平行键模型（Linear Parallel Bond）

命名 `linearpbond`，是模拟**岩石、混凝土等胶结材料**最常用的模型。它相当于在两实体之间"沉积"了一段有限尺寸的胶结材料，可同时传递**力和力矩**。

平行键分量与线性分量**并联**：线性分量提供无拉摩擦行为，平行键提供弹性黏结。

**2D 键截面（矩形，单位厚度，半径 $\bar R$）**

- 截面面积：$\bar A = 2\bar R$
- 截面惯性矩：$\bar I = \dfrac{2}{3}\bar R^3$

**键内应力（决定破坏）**

键材料外围的最大应力由轴力与弯矩贡献叠加：

$$\bar\sigma = \frac{\bar F_n}{\bar A} + \bar\beta\, \frac{|\bar M_b|\,\bar R}{\bar I}$$

$$\bar\tau = \frac{|\bar F_s|}{\bar A}$$

其中 $\bar F_n$、$\bar F_s$ 为平行键法向/切向力（拉为正），$\bar M_b$ 为弯矩，$\bar\beta \in [0,1]$ 为弯矩贡献系数（默认 1）。

**破坏准则**

- 拉伸破坏：$\bar\sigma \ge \bar\sigma_c$（抗拉强度）
- 剪切破坏：$\bar\tau \ge \bar c$（内聚力）

一旦破坏，平行键及伴生的力、力矩、刚度一并移除，模型退化为线性模型。

| 关键参数 | 含义 |
|----------|------|
| `pb_emod` / `pb_kratio` | 平行键有效模量与法切刚度比 |
| `pb_ten` $\bar\sigma_c$ | 平行键抗拉强度（应力单位） |
| `pb_coh` $\bar c$ | 平行键内聚力（应力单位） |
| `pb_fa` | 平行键摩擦角 |

## 其他常用模型（简表）

| 模型 | 名称 | 特点与用途 |
|------|------|-----------|
| Hertz | `hertz` | 非线性法向（赫兹接触），无拉、无黏结；模拟弹塑性颗粒 |
| 滚动阻力线性 | `rrlinear` | 线性模型 + 抗滚动阻力，抑制颗粒过度滚动，模拟角砾/颗粒堆积 |
| 光滑节理 | `smoothjoint` | 模拟岩体节理面的滑移，用于 DFN 岩石 |
| 平直节理 | `flatjoint` | 模拟颗粒界面上的平直节理，含节理接触与黏结，适合硬岩 |
| 软键 | `softbond` | 细观黏结，可自定义软化，适合软岩/黏土质胶结 |
| 伯格斯 | `burger` | 黏弹性（蠕变）模型，模拟沥青、黏性材料 |

## 如何选择接触模型

| 场景 | 推荐模型 |
|------|----------|
| 无黏结颗粒堆积、砂土、松散体 | `linear` |
| 仅需简单黏结的颗粒材料 | `linearcbond` |
| 岩石、混凝土等胶结材料（标准） | `linearpbond` |
| 含节理的岩体 | `smoothjoint` / `flatjoint` |
| 需要抑制过度滚动 | `rrlinear` |

> 参数标定（calibration）是使用接触模型的关键：通过调整刚度、强度、摩擦等参数，使宏观力学响应（单轴压缩强度、弹性模量等）与试验吻合。相关内容见「[参数标定](./material-calibration)」。
