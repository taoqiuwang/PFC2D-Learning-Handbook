# 参数标定

参数标定（calibration）是 PFC 建模中最关键、也最耗时的一步：通过调整**微观参数**（颗粒与接触/键的刚度、强度、摩擦等），使数值试样表现出的**宏观力学响应**（弹性模量、泊松比、抗压/抗拉强度、内摩擦角等）与目标值吻合。

> 目标值通常来自室内试验（单轴压缩、三轴、巴西劈裂等）或已知材料手册。本章参考 Potyondy & Cundall 的经典标定方法，并与「[单轴压缩案例](../examples/uniaxial-compression)」配套。

## 一、为什么要标定

PFC 的输入是微观参数（如 `emod`、`pb_ten`），而工程关心的是宏观参数（如 $E$、$\sigma_c$）。两者之间**没有解析公式**，只能通过数值试验反推对应关系。若不标定，模型给出的强度、变形可能和真实材料相差数倍。

## 二、目标宏观参数

岩石类材料通常需要标定以下指标：

| 宏观参数 | 符号 | 来源试验 |
|----------|------|----------|
| 弹性模量 | $E$ | 单轴压缩 |
| 泊松比 | $\nu$ | 单轴压缩（测侧向变形） |
| 单轴抗压强度 | $\sigma_c$（UCS） | 单轴压缩 |
| 抗拉强度 | $\sigma_t$ | 直接拉伸 / 巴西劈裂 |
| 内聚力、内摩擦角 | $c$、$\phi$ | 三轴（或双轴）压缩 |

## 三、微观→宏观对应关系

一条经验规律：**一次只调一个微观参数，观察它主要影响哪个宏观量**。

| 微观参数 | 主要影响的宏观量 | 趋势 |
|----------|-----------------|------|
| `emod` / `pb_emod`（有效模量） | 弹性模量 $E$ | $E$ 近似随 `emod` 线性增大 |
| `kratio`（法切刚度比） | 泊松比 $\nu$ | $\nu$ 随 `kratio` 增大 |
| `pb_ten`（键抗拉强度） | 抗拉强度 $\sigma_t$ | 近似直接对应 |
| `pb_coh`（键内聚力） | 抗压强度 $\sigma_c$ | 增大则 $\sigma_c$ 增大 |
| `fric` / `pb_fa`（摩擦） | 内摩擦角 $\phi$、峰后行为 | 增大则 $\phi$ 增大 |

> 注意：这些关系存在耦合，且受**颗粒粒径、孔隙率、试样尺寸**影响。标定时应固定几何与粒径，再单独扫参。

## 四、标定流程

### 第 1 步：固定几何

- 确定**颗粒粒径**（或粒径分布）与**目标孔隙率**，全程保持不变。
- 粒径越细，试样越均匀、离散性越小，但计算量急剧增大。经验上试样宽度至少容纳 15–30 个颗粒。

### 第 2 步：标定弹性参数 $E$、$\nu$

做单轴压缩（弹性段），按线弹性关系：

$$\sigma = E\,\varepsilon,\qquad \nu = -\frac{\varepsilon_{lat}}{\varepsilon_{ax}}$$

- 调整 `emod` 使数值 $E$ 逼近目标值；
- 调整 `kratio` 使数值 $\nu$ 逼近目标值。

### 第 3 步：标定强度 $\sigma_t$、$\sigma_c$

- **直接拉伸试验**标定 $\sigma_t$：只调 `pb_ten`，使峰值拉伸应力等于目标抗拉强度。
- **单轴压缩**标定 $\sigma_c$：再调 `pb_coh`（必要时微调 `pb_ten`），使峰值轴向应力等于目标 UCS。

### 第 4 步：标定摩擦角 $\phi$（需要时）

做**双轴/三轴压缩**（不同围压），拟合 Mohr-Coulomb 包络：

$$\tau = c + \sigma_n \tan\phi$$

调整 `fric`（或平行键的 `pb_fa`），使数值 $c$、$\phi$ 匹配目标。

## 五、常用标定试验汇总

| 试验 | 标定目标 | 关键命令/要点 |
|------|----------|--------------|
| 单轴压缩 | $E$、$\sigma_c$ | 上下压板相向运动，见[案例](../examples/uniaxial-compression) |
| 直接拉伸 | $\sigma_t$ | 两端固定并施加相反速度 |
| 巴西劈裂 | 间接 $\sigma_t$ | 圆盘试样径向压缩 |
| 双轴/三轴 | $c$、$\phi$ | 侧向用 `wall servo` 维持围压 |

## 六、注意事项与技巧

1. **先弹性后强度**：先标 $E$、$\nu$（弹性段，与强度无关），再标强度，减少耦合。
2. **一次一个参数**：扫参时每次只改一个量，否则无法判断贡献。
3. **多次实现取平均**：颗粒随机生成带来离散性，同一参数应生成多个试样取均值。
4. **记录标定曲线**：把「微观参数 → 宏观响应」的散点记下来，便于插值收敛。
5. **平行键的压拉比问题**：平行键模型得到的 $\sigma_c/\sigma_t$ 常偏低，若目标压拉比较高，改用 `flatjoint`（平直节理）模型。

## 七、参数标定脚本化

标定需要大量重复试验，建议用脚本（FISH 或外部 Python）自动：

1. 批量生成不同参数的试样；
2. 自动执行单轴压缩并提取峰值；
3. 汇总结果，绘制「参数 → 强度」曲线，寻找与目标匹配的参数组合。
